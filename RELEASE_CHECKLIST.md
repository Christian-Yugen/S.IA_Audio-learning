# Checklist de publicação — Chrome Web Store

## Código e pacote

- [x] Manifest V3.
- [x] Propósito único definido.
- [x] Permissões mínimas revisadas.
- [x] Sem código remoto.
- [x] Testes automatizados do motor adaptativo.
- [x] Manifesto e JavaScript validados.
- [x] Empacotador com allowlist de arquivos.
- [x] `manifest.json` na raiz do ZIP.
- [ ] Teste manual final da versão empacotada.
- [ ] Conferir se a versão do ZIP é superior à última enviada à loja.

## Privacidade

- [x] Política de privacidade redigida.
- [x] Dados e processamento local documentados.
- [x] Justificativas de permissões redigidas.
- [x] Declaração de ausência de código remoto.
- [ ] Definir e-mail oficial de suporte.
- [ ] Publicar a política de privacidade em URL HTTPS pública.
- [ ] Inserir a URL no Developer Dashboard.
- [ ] Conferir consistência entre dashboard, política, manifesto e ficha.

## Ficha da loja

- [x] Nome.
- [x] Resumo curto.
- [x] Descrição detalhada.
- [x] Categoria e idioma sugeridos.
- [x] Propósito único.
- [x] Instruções de revisão.
- [x] Ícone 128x128 com margem adequada.
- [ ] Pelo menos uma captura 1280x800 ou 640x400.
- [x] Imagem promocional 440x280.
- [ ] Marquee 1400x560, opcional.
- [ ] URL oficial da marca, se disponível.

## Publicação

- [ ] Registrar ou confirmar a conta de desenvolvedor.
- [ ] Criar novo item no Chrome Web Store Developer Dashboard.
- [ ] Enviar o ZIP.
- [ ] Preencher Store Listing.
- [ ] Preencher Privacy practices.
- [ ] Selecionar “Não listada” para o primeiro teste controlado.
- [ ] Adicionar testadores, se usar distribuição privada.
- [ ] Enviar para revisão.
- [ ] Registrar o ID definitivo da extensão.
