# Histórico técnico

Esta pasta preserva documentos de análise, decisões de implementação e diagnósticos que explicam a evolução da S·IA até a versão 1.8.5.

Os documentos históricos não substituem o [Documento Mestre](../governance/MASTER-SIA-EXPANSION.md). Quando houver conflito entre um documento histórico e uma regra vigente, a regra vigente prevalece.

Arquivos binários, áudios de teste, vídeos, perfis de navegador, logs não revisados e árvores completas de compilação não são mantidos aqui. Eles permanecem fora do repositório público por razões de privacidade, tamanho e auditoria de licença.
