# S·IA 1.11.1 — estabilização (candidata)

## Problema e resultado

Na 1.11.0, mover a voz ou testar o espacial podia ativar Piper sem escolha;
o automático também podia religar o espacial. O painel mostrava posição do
vídeo sem processamento correspondente e os empacotadores omitiam dependências.
A 1.11.1 preserva a seleção do usuário, aplica posições somente à voz neural,
compartilha os presets e recusa pacotes com referências ausentes.

## Alterações

- Catálogo único `extension/audio-settings.js` para popup, painel, provedor e heurística.
- Voz do navegador preservada até seleção explícita de Piper. Teste e preparação
  neural retornam orientação quando Piper não foi selecionado.
- Automático por palavras-chave opt-in; respeita bypass espacial. Ajuste manual
  desliga a automação e fica persistido; ligar/desligar espacial conserva coordenadas.
- Expressões compostas reconhecidas com limites de palavras, sem casar `key` com `keyboard`.
- Retirado o controle espacial do vídeo sem implementação. A atenuação de volume permanece.
- Configurações avançadas recolhidas; opções essenciais e histórico continuam disponíveis.
- Descrições sem HRTF, porcentagens de fadiga, diagnóstico automático de mono ou calibração absoluta.
- Radar com teclado e estado acessível; seleção por botões com `aria-pressed`.
- Empacotadores Python e PowerShell usam a mesma allowlist JSON e verificam
  manifesto, HTML e injeção dinâmica. Python também verifica o CRC do ZIP.
- CI ampliada para todos os testes JS, empacotamento Python e baseline protegido.

## Instalação

Baixe o ZIP da branch desta correção pelo GitHub (conectado à conta com acesso).
Extraia para uma pasta permanente e, em `chrome://extensions`, desative a cópia
antiga, ative Modo do desenvolvedor e use Carregar sem compactação na pasta
`extension`, que contém `manifest.json`. Confirme 1.11.1 e recarregue a aula.

Para gerar um pacote contendo somente a extensão:

```sh
python extension/scripts/package-extension.py --output-directory /caminho/fora/do/repositorio
```

No Windows há também `extension/scripts/package-extension.ps1`.
O script PowerShell não foi executado no ambiente Linux; o pacote Python foi
criado, extraído e comparado byte a byte com a origem.

## Evidências e limite de validação

Veja [validação antes/depois](../reports/1.11.1-validation.md).
Esta versão é candidata: falta teste auditivo em aula real no Chrome.
Não há transcrição do áudio bruto de vídeos sem legendas nesta versão.

## Rollback

Desative 1.11.1 e recarregue `extension` do commit
`8119326e66cf77067fb77cdc035713c831def080` (1.11.0).
Não é necessária migração destrutiva de dados. A correção não modifica o sincronizador
nem os adaptadores das plataformas. Não apague a pasta da versão usada pelo Chrome.
