# S·IA 1.8.28 — Captions fragmentadas estáveis no YouTube

**Status:** release local de reconstrução, baseada na 1.8.22 funcional e preparada para validação no Chrome real.

## Causa comprovada

A partir da evolução para captions fragmentadas, o adapter passou a manter um snapshot externo do fallback IOS e, ao mesmo tempo, ler a `TextTrack` nativa do player. Quando o snapshot externo era classificado como fragmentado, cada `scan()` que encontrava uma palavra na faixa nativa executava `aggregator.reset()` antes de enviar a cue ao agregador.

Esse reset apagava a frase parcial a cada polling. Como consequência, palavras consecutivas não chegavam ao agregador como uma sequência contínua: a S·IA podia falar fragmentos isolados, reiniciar a fila ou não emitir uma fala completa. Essa causa explica melhor o comportamento observado após a 1.8.22 do que a hipótese isolada de troca de qualidade do stream.

## Correção

A 1.8.28 remove o reset indevido do ramo de `TextTrack` nativa. O buffer do agregador agora permanece vivo entre cues nativas e só é limpo nas situações corretas: troca real de vídeo/track, seek para trás, anúncio ou conclusão normal da frase.

O snapshot externo continua disponível como fallback temporal e não substitui a faixa nativa quando ela possui cues. A seleção de uma única cue externa, o agrupamento de microcues e a proteção contra overlay sem timing continuam ativos. O popup também mantém o reload quando a aba retorna `alreadyActive`, para evitar bundles antigos presos em abas abertas.

## Regra de emissão

A S·IA deve enviar uma única cue agregada por sentença confirmada. Cues individuais sem pontuação continuam no buffer até que a sequência, o tempo máximo ou a pontuação final permitam liberar o grupo. O overlay visual do YouTube não é fonte de fala.

## Invariantes preservadas

| Invariante | Estado |
|---|---|
| Baseline Coursera | Não alterado |
| Udemy | Não alterado |
| Núcleo Browser/Piper | Compartilhado e não duplicado |
| Fallback Web → IOS | Preservado |
| Legenda visual | `TextTrack.mode` não é alterado |
| Timing | Sem início/fim confirmados, não fala |
| YouTube | Manual, opt-in e restrito a `/watch?v=...` |
| Rollback | 1.8.27 disponível |

## Verificação local

| Verificação | Resultado |
|---|---:|
| Teste nativo fragmentado isolado | Uma frase |
| Teste nativo + snapshot externo fragmentado | Uma frase |
| Testes direcionados | 21 aprovados, 0 falhas |
| Suíte completa | 104 aprovados, 0 falhas |
| Coursera/Udemy/Piper | Sem falhas na suíte compartilhada |

## Limite honesto

A correção foi reproduzida no harness com o mesmo padrão de coexistência entre `TextTrack` e snapshot externo, mas a confirmação definitiva precisa ocorrer no vídeo do usuário com a extensão 1.8.28 carregada. Não será afirmado que o áudio físico já foi validado no Chrome real antes desse teste.

## Instalação limpa

Desative as versões anteriores em `chrome://extensions`, carregue somente a pasta descompactada da 1.8.28, feche todas as abas antigas do YouTube e encerre completamente o Chrome. Ao abrir novamente, abra uma nova URL `/watch?v=...`, selecione YouTube e clique em “Aplicar nesta aba”. Depois selecione o Piper e reproduza o vídeo.

## Rollback

Se a 1.8.28 ainda apresentar gagueira ou ausência de fala, desative-a e retorne à 1.8.22, que permanece como baseline funcional conhecida, para não misturar resultados de versões experimentais.
