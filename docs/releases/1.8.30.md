# S·IA 1.8.30 — Sentença completa com prosódia contínua no YouTube

**Status:** release local de correção, baseada no caminho temporal da 1.8.22 e nas proteções fragmentadas posteriores.

## Problema corrigido

A 1.8.29 eliminou a gagueira causada pelo flush prematuro, mas ainda podia emitir pequenos grupos quando a legenda nativa entregava palavras com intervalos longos. Cada grupo era enviado ao Piper como uma utterance independente. O Piper interpretava o fim de cada utterance como fim de frase, produzindo uma entonação descendente e artificial entre palavras que ainda pertenciam à mesma sentença.

## Correção aplicada

A 1.8.30 usa lookahead limitado na `TextTrack` nativa. Quando a faixa contém microcues consecutivas, com timing confirmado, continuidade temporal e pontuação final dentro do limite seguro, o adapter monta a sentença do primeiro fragmento até a pontuação e envia uma única cue agregada ao núcleo Browser/Piper.

Quando a cue seguinte aparece, a chave temporal da sentença completa impede uma segunda emissão. O lookahead não atravessa pontuação final, não atravessa uma lacuna excessiva, não ultrapassa o limite de span e não é aplicado a captions normais que já chegam como frases completas.

O caminho de fallback IOS continua preservado para o caso em que o timedtext Web venha vazio. O overlay visual continua sendo apenas visual e nunca é usado como fonte de fala.

## Invariantes preservadas

| Invariante | Estado |
|---|---|
| Coursera | Não alterado |
| Udemy | Não alterado |
| Legenda inteira YouTube | Caminho imediato preservado |
| Legenda fragmentada | Uma síntese por sentença completa |
| Prosódia | Sem encerramento artificial entre palavras da mesma sentença |
| Timing | Apenas cues com início e fim confirmados |
| Legenda visual | `TextTrack.mode` não é alterado |
| Áudio | Fila Browser/Piper compartilhada |
| Fallback | Web → IOS local preservado |
| Rollback | 1.8.29 disponível |

## Verificação local

| Verificação | Resultado |
|---|---:|
| Lookahead da primeira palavra até pontuação | Uma emissão completa |
| Avanço para a segunda palavra | Nenhuma reemissão |
| Lacunas de 700 ms | Uma sentença |
| Sentença longa com gaps de 850 ms | Uma sentença |
| TextTrack + snapshot externo | Uma sentença |
| Testes YouTube | 24 aprovados, 0 falhas |
| Suíte completa | 107 aprovados, 0 falhas |

## Limite honesto

A validação comprova que a fila recebe uma única sentença completa quando as cues futuras estão disponíveis na `TextTrack`. A confirmação da qualidade prosódica depende da audição do Piper no Chrome real; isso não é afirmado como fisicamente validado antes do teste do usuário.

## Instalação e teste

Desative as versões anteriores em `chrome://extensions`, carregue somente a pasta descompactada da 1.8.30, feche as abas antigas do YouTube e reinicie completamente o Chrome. Abra uma nova URL `/watch?v=...`, selecione YouTube, clique em “Aplicar nesta aba”, selecione Piper e reproduza um vídeo com legenda fragmentada.

O resultado esperado é a sentença ser pronunciada como uma unidade contínua, sem a queda de entonação após cada grupo de duas ou três palavras. A legenda visual continua controlada pelo próprio YouTube.

## Rollback

Se a 1.8.30 apresentar comportamento inesperado, desative-a e retorne à 1.8.29. Para recuperar a última base funcional conhecida do YouTube, use a 1.8.22.
