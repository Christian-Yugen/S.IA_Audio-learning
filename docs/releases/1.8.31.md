# S·IA 1.8.31 — Continuidade prosódica entre linhas no YouTube

**Status:** release de correção baseada na 1.8.30.

## Problema observado

A 1.8.30 já reunia cues futuras da mesma sentença quando a sequência permanecia na mesma linha visual. Porém, quando a última palavra de uma linha era seguida pela continuação na linha visual abaixo, o intervalo temporal podia ultrapassar a janela comum de continuidade. O agrupamento então tratava a primeira linha como uma unidade encerrada e a linha seguinte como início de outra fala.

O resultado era uma entonação final artificial na última palavra da primeira linha e uma nova entonação inicial na palavra seguinte, embora o texto ainda fosse a mesma frase.

## Correção aplicada

A 1.8.31 reconhece continuidade temporal por `sequenceId` consecutivo. Quando os fragmentos são consecutivos no transcript, a sequência não contém pontuação final e o intervalo permanece dentro do limite preventivo de 2,5 segundos, a mudança visual de linha não encerra a sentença. O adapter reúne os fragmentos até a pontuação final e envia uma única cue completa ao núcleo Browser/Piper.

A regra é limitada: não atravessa ponto, interrogação, exclamação ou reticências; não atravessa troca de vídeo, seek, anúncio ou track; não ultrapassa 10 segundos de span; e não é usada para captions normais que já chegam como frases completas.

## Invariantes preservadas

| Invariante | Estado |
|---|---|
| Coursera | Não alterado |
| Udemy | Não alterado |
| Legenda inteira YouTube | Caminho imediato preservado |
| Fragmentos na mesma linha | Uma síntese por sentença |
| Fragmentos em linhas diferentes | Uma síntese por sentença quando `sequenceId` é consecutivo |
| Timing | Apenas cues com início e fim confirmados |
| Legenda visual | `TextTrack.mode` não é alterado |
| Áudio | Fila Browser/Piper compartilhada |
| Fallback | Web → IOS local preservado |
| Rollback | 1.8.30 disponível |

## Verificação local

| Verificação | Resultado |
|---|---:|
| Continuação na linha visual seguinte | Uma emissão completa |
| Avanço para fragmentos posteriores | Nenhuma reemissão |
| Fragmentos com lacuna de 700 ms | Uma sentença |
| Sentença longa com gaps de 850 ms | Uma sentença |
| TextTrack + snapshot externo | Uma sentença |
| Testes YouTube | 25 aprovados, 0 falhas |
| Suíte completa | 108 aprovados, 0 falhas |

## Limite honesto

A validação comprova a unidade temporal única quando o transcript fornece `sequenceId` consecutivo. A confirmação da qualidade prosódica final depende da audição no Chrome real do usuário.

## Instalação e teste

Desative as versões anteriores em `chrome://extensions`, carregue somente a pasta descompactada da 1.8.31, feche as abas antigas do YouTube e reinicie completamente o Chrome. Abra uma nova URL `/watch?v=...`, selecione YouTube, clique em “Aplicar nesta aba”, selecione Piper e reproduza o mesmo vídeo que apresentou a quebra entre linhas.

O resultado esperado é que a última palavra da linha superior e a continuação da linha inferior sejam pronunciadas como parte da mesma frase, sem queda de entonação entre elas.

## Rollback

Se a 1.8.31 apresentar comportamento inesperado, desative-a e retorne à 1.8.30. Para recuperar a última base funcional conhecida do YouTube, use a 1.8.22.
