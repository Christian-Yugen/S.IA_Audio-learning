# S·IA 1.8.32 — Continuidade nativa entre linhas sem ID explícito

**Status:** release de correção baseada na 1.8.31.

## Problema corrigido

A 1.8.31 já mantinha a sentença unificada quando o transcript fornecia `sequenceId` consecutivo. Entretanto, objetos `TextTrackCue` do navegador podem não fornecer `sequenceId` nem um `id` útil; em alguns casos o `id` existe como string vazia. Nessa situação, a transição entre a última palavra da linha superior e a primeira palavra da linha inferior podia não ser reconhecida como continuidade.

O sintoma era uma fronteira acústica perceptível: a última palavra da primeira linha recebia entonação de encerramento e a próxima palavra começava como uma nova frase.

## Correção aplicada

A 1.8.32 atribui um identificador de sequência local às cues nativas sem ID, usando a ordem temporal estável da própria `TextTrack`. Esse índice é usado somente para reconhecer a continuidade durante a montagem da sentença. A regra atravessa gaps temporais maiores que a janela comum apenas quando a sequência é consecutiva, não há pontuação final e o span total permanece dentro do limite preventivo.

O adapter reúne a sentença do primeiro fragmento até a pontuação final e envia uma única cue ao núcleo Browser/Piper. A cue seguinte não reemite a fala completa porque a chave temporal agregada permanece deduplicada.

## Invariantes preservadas

| Invariante | Estado |
|---|---|
| Coursera | Não alterado |
| Udemy | Não alterado |
| Legenda inteira YouTube | Caminho imediato preservado |
| Fragmentos na mesma linha | Uma síntese por sentença |
| Fragmentos em linhas diferentes | Uma síntese por sentença mesmo sem ID nativo |
| Timing | Apenas cues com início e fim confirmados |
| Legenda visual | `TextTrack.mode` não é alterado |
| Áudio | Fila Browser/Piper compartilhada |
| Fallback | Web → IOS local preservado |
| Rollback | 1.8.31 disponível |

## Verificação local

| Verificação | Resultado |
|---|---:|
| Continuação entre linhas com `sequenceId` | Uma emissão completa |
| Continuação entre linhas sem ID | Uma emissão completa |
| `TextTrackCue.id` vazio | Uma emissão completa |
| Avanço para a cue seguinte | Nenhuma reemissão |
| Testes YouTube | 25 aprovados, 0 falhas |
| Suíte completa | 108 aprovados, 0 falhas |

## Limite honesto

A validação comprova o agrupamento temporal único no adapter quando as cues completas estão disponíveis na `TextTrack`. A confirmação da ausência de corte acústico depende da audição no Chrome real do usuário.

## Instalação e teste

Desative as versões anteriores em `chrome://extensions`, carregue somente a pasta descompactada da 1.8.32, feche as abas antigas do YouTube e reinicie completamente o Chrome. Abra uma nova URL `/watch?v=...`, selecione YouTube, clique em “Aplicar nesta aba”, selecione Piper e reproduza o vídeo que apresenta a quebra de linha.

O resultado esperado é que a última palavra da primeira linha e a palavra seguinte da linha inferior tenham continuidade de uma mesma frase, sem queda de entonação entre elas.

## Rollback

Se a 1.8.32 apresentar comportamento inesperado, desative-a e retorne à 1.8.31. Para recuperar a última base funcional conhecida do YouTube, use a 1.8.22.
