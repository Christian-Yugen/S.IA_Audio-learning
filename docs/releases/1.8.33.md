# S·IA 1.8.33 — Companion de estudo ativo local

**Status:** release de integração do primeiro MVP pedagógico local.

## Objetivo

A 1.8.33 acrescenta ao S·IA Companion um ciclo opcional de aprendizagem ativa sem substituir o núcleo existente de leitura, voz, fila, sincronização, Piper ou fallback. O recurso transforma uma cue temporal segura em uma marcação de estudo e em um cartão de recuperação que o estudante pode revisar posteriormente.

O desenho é local por padrão: não há servidor, analytics, envio de legendas, inferência externa ou sincronização em nuvem. O tempo assistido continua sendo apenas contexto de uso; não é apresentado como domínio ou diagnóstico de capacidade.

## Recursos entregues

| Recurso | Comportamento |
|---|---|
| Marcação temporal | Cria uma marcação a partir da cue atual quando texto, início e fim estão confirmados. |
| Tipos de marcação | Permite classificar o trecho como conceito, exemplo, dúvida ou importante. |
| Pergunta de recuperação | Gera uma pergunta determinística e local a partir do trecho salvo. |
| Cartão de estudo | Mantém pergunta, trecho original, timing e estado de revisão. |
| Resposta do estudante | Registra localmente a resposta digitada durante a revisão. |
| Avaliação | Oferece **Lembrei**, **Parcial** e **Esqueci**. |
| Revisão espaçada | Calcula o próximo vencimento com uma regra simples e determinística. |
| Replay | Retorna ao timestamp da marcação usando o mesmo caminho de voz existente. |
| Limpeza | Permite apagar as marcações e cartões locais da aula atual. |

## Fluxo no Companion

1. Abra o **S·IA Companion** durante uma aula compatível.
2. Aguarde uma cue segura aparecer como contexto atual.
3. Escolha o tipo de marcação e clique em **Marcar cue atual**.
4. Quando houver cartão vencido, leia a pergunta e tente responder antes de revelar o trecho original.
5. Avalie a lembrança. Para **Lembrei** ou **Parcial**, informe uma resposta; **Esqueci** pode ser registrado sem resposta.
6. Use **Reproduzir marcação** para voltar ao trecho, quando necessário.

O botão de marcação permanece desabilitado quando não há cue segura. Texto visual sem início e fim temporais confirmados não vira marcação temporal nem cartão.

## Armazenamento e privacidade

As marcações e cartões são mantidos em `chrome.storage.local`, separados por plataforma e aula. O registro inclui apenas o texto seguro da cue, identificadores locais da aula, URL/título, início/fim, tipo, pergunta, resposta e metadados de revisão. O Companion oferece limpeza do estudo. Nenhum desses dados é enviado para servidor pela extensão.

## Invariantes preservadas

| Invariante | Estado |
|---|---|
| Caminho de voz Coursera | Preservado; o Learning Core apenas observa e registra contexto seguro. |
| Caminho de voz Udemy | Preservado; integração aditiva no mesmo content script. |
| YouTube | O Learning Core só acompanha o caminho já permitido pelo opt-in manual. |
| Fila Browser/Piper/sync/fallback | Uma única fila compartilhada; nenhum motor paralelo foi criado. |
| Timing | Somente cues com texto, início e fim confirmados entram no estudo temporal. |
| Privacidade | Dados pedagógicos ficam locais e apagáveis. |
| Compatibilidade | Histórico, Recall, favoritos, notas, replay e exportação existentes permanecem no Companion. |

## Limite honesto

A release foi validada por testes automatizados e inspeção do pacote no sandbox. Isso não substitui a confirmação física no Chrome do usuário com uma aula real, especialmente para verificar a experiência visual do Companion e o replay de cada plataforma. Esta release não pretende corrigir os problemas de prosódia ou fragmentação do YouTube; o foco é o MVP pedagógico aditivo.

## Rollback

Se o fluxo pedagógico apresentar comportamento inesperado, desative a 1.8.33 e retorne à versão anterior disponível. A leitura e a voz devem continuar sendo avaliadas separadamente do estudo ativo; a camada pedagógica não deve controlar nem interromper a fila de áudio.
