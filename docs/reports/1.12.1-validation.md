# S.IA 1.12.1 — Correção de carregamento no Chrome

## Causa e correção
O manifesto 1.12.0 usava /pt-br/* nos matches de web_accessible_resources.
O Chrome exige /* nessa seção. Corrigidos somente os dois padrões do AI Guru
nessa seção; content_scripts continua restrito a /pt-br/*.
Versão atualizada para 1.12.1. Nenhum código de execução das plataformas alterado.

Referência: https://developer.chrome.com/docs/extensions/reference/manifest/web-accessible-resources
